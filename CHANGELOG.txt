How the versions work (the third number is the ZMK version):
- v0.0.3.N        versions for ZMK v0.3 (branch `zmk-v0.3`, and `main` while it is on ZMK v0.3)
- v0.0.4.N        versions for the next ZMK version (v0.4)
- New work is developed on the branch `dev`
